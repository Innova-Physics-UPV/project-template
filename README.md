## How work reaches this repository

1. **Tasks are issues.** Direction opens each one from the task form.
2. **Work happens on a branch created from the issue.**
3. **Nobody pushes to `main`, Direction included.** Changes arrive by pull request, with signed commits and Direction's approval.
